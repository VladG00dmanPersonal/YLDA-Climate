# YLDA-Climate

Анализ удовлетворённости клиентов климатическим оборудованием: исследование комфорта сотрудников в офисах разных стран при работе систем кондиционирования, вентиляции и смешанного типа.

## Цель

Провести комплексный анализ данных о комфорте использования климатического оборудования, определить, в какой тип оборудования (кондиционирование, вентиляция, смешанный тип) стоит инвестировать больше ресурсов в зависимости от региона, выявить ключевые факторы, влияющие на комфорт, и дать рекомендации по развитию бизнеса.

## Что сделано

Весь анализ собран в одной тетрадке — [`climate_analysis.ipynb`](climate_analysis.ipynb):

1. **Предобработка данных** — переименование столбцов по PEP8, приведение типов, удаление дубликатов, обработка выбросов (температура 77 °C в помещении, скорость воздуха 63 м/с, рост 5 см и т. п.) и заполнение пропусков.
2. **Исследовательский анализ** — распределения по странам, полу, возрасту, климатическим зонам и типам оборудования, корреляционный анализ (`dython`, шкала Чеддока).
3. **Расчёты** — возрастные группы, средняя комфортная температура по группам, медианы температуры и влажности по типу охлаждения, доля удовлетворённых по стране и полу, соответствие влажности офисному нормативу (40–60 %).
4. **Регрессия** — линейная модель температуры в помещении от типа охлаждения и других факторов.
5. **Проверка гипотез** — непараметрические тесты (Краскела–Уоллиса, Манна–Уитни, корреляция Кендалла).

## Основные выводы

- **Способ охлаждения** статистически значимо влияет на *ощущение температуры*, но значимой связи с *оценкой комфорта* не выявлено (возможно, из-за малого объёма выборки).
- **Пол, возрастная группа и страна** значимо влияют на оценку комфорта.
- **Число рекламаций** монотонно связано с оценкой комфорта: больше жалоб — ниже оценка.
- **Состояние вентилятора** на среднюю оценку комфорта не влияет.
- По выбранным признакам линейная регрессия **не позволяет точно предсказать** температуру в помещении — нужны дополнительные признаки или другая обработка.
- При кондиционировании температура в помещении в среднем ниже, чем при вентиляции или смешанных системах; смешанные системы и кондиционирование встречаются чаще всего.

## Данные

[`data/data.csv`](data/data.csv) — исходный датасет (≈480 наблюдений, разделитель `;`): год, сезон, климат, город, страна, тип охлаждения и отопления, возраст, пол, субъективные оценки температуры и комфорта, теплоизоляция одежды, температура и влажность, скорость воздуха, рост, вес, состояние окон/дверей/вентилятора, количество рекламаций.

Промежуточные файлы (`cleared_data.csv`, `researched_data.csv` и др.) создаются тетрадкой при запуске в папке `data/` и в репозиторий не попадают.

## Запуск

Нужен Python 3.10+.

```bash
git clone https://github.com/VladG00dmanPersonal/YLDA-Climate.git
cd YLDA-Climate
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook climate_analysis.ipynb
```

Тетрадку нужно запускать из корня репозитория — пути к данным указаны относительно него.
